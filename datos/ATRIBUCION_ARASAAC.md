# Atribución de pictogramas ARASAAC

Los pictogramas de este proyecto proceden de **ARASAAC** (Centro Aragonés para la Comunicación Aumentativa y Alternativa).

- Autor de los pictogramas: **Sergio Palao**
- Procedencia: https://arasaac.org
- Licencia: **Creative Commons BY-NC-SA** (Reconocimiento – No Comercial – Compartir Igual)
- Gobierno de Aragón

Uso educativo no comercial para el trabajo de curso 1ASI0404 (PictoChef · Asociación Educativa Kallpa).

Imagen: `static.arasaac.org/pictograms/{id}/{id}_500.png` (descarga: `python codigo/descargar_pictogramas.py`).
