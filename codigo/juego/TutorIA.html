¿Qué es TutorIA?

Es el motor de Q-Learning de la Sra. Tomate. Cada vez que el jugador se equivoca, pide ayuda o se queda en silencio, TutorIA mira el estado (fase, errores seguidos, nivel, tarjetas en pantalla, rapidez, última ayuda, qué rasgo comparte el error y cuál es el rasgo más informativo) y elige el tipo de ayuda: animar, pista de un rasgo, pista doble o pista directa.

Recompensa: +1 si el siguiente intento acierta, −0,5 si falla, −0,4 si repite el mismo error, menos el costo de la ayuda (animar 0 · rasgo 0,1 · doble 0,4 · directa 1). Se entrenó con jugadores simulados de cinco perfiles.

Entrenamiento

Promedio por bloque de episodios. ε baja de 0,3 a 0,02; α = 1/(1+n)0,6 por par (estado, acción).

Comparación de políticas

q = TutorIA · ig = regla fija del Hito 1 · aleatoria = tipo de ayuda al azar · sin_pista = solo anima. Mismas recetas, niveles y semillas para todas (python TutorIA.py evaluar).

Política aprendida

Acción con mayor Q (entre paréntesis, las veces que se visitó el estado) para nivel medio, 4-6 tarjetas y respuesta lenta.

Simular una partida

Un jugador simulado juega una receta con la tabla Q real que usa el juego. Las tarjetas rojas son las decisiones de TutorIA.
